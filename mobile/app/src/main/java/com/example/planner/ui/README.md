# UI слой

## Назначение
Модуль отображает данные IT Planner и пользовательские сценарии на Jetpack Compose, опираясь на MVVM и единый поток данных.

## Стек
- Jetpack Compose + Material3 + Navigation Compose
- Hilt для DI
- Kotlin coroutines, StateFlow/SharedFlow
- ActivityResult API для выбора и загрузки файлов
- Android 26–36, Compose BOM

## Структура
- components/ — переиспользуемые элементы (кнопки, карточки, диалоги, инпуты)
- navigation/ — маршруты (`NavRoutes`) и хост (`AppNavHost`)
- screens/ — экраны и их «чистые» версии без данных
- theme/ — цвета, типографика, тема
- viewmodel/ — ViewModel с состоянием и бизнес-логикой UI

## Основные экраны и сценарии
- Аутентификация: Login, Register, Verify; переключение табов, повторная отправка кода, показ ошибок и лоадеров.
- Проекты: список, создание, удаление, переход в профиль.
- Детали проекта: вкладки Tasks / Members / Repository.
  - Tasks — статусы TO_DO/IN_PROGRESS/REVIEW/IN_TEST/DONE, срочность и сложность, переход в задачу.
  - Members — приглашение по e-mail, удаление участника, смена роли.
  - Repository — загрузка, скачивание и удаление файлов, отображение выбранного имени.
- Детали задачи: изменение статуса/приоритета/сложности/описания, назначение ответственного, загрузка/скачивание/удаление вложений, трекинг часов и история записей.
- Профиль: просмотр и обновление имени/аватара через `ProfileViewModel`.

## Состояние и эффекты
- StateFlow хранит долгоживущее состояние экранов.
- SharedFlow используется для одноразовых событий (скачивание файлов).
- Ошибки приводятся к человекочитаемым сообщениям; есть `clearError()` и reset-флаги после успешных действий.
